# UVE Desktop Video Editor V4

Dies ist das aktualisierte Entwicklungs-Paket. `UVE_DESKTOP_VIDEO_EDITOR_IMPLEMENTATION_V4.md` ist verbindlich und ersetzt bei Widersprüchen frühere V1–V3-Spezifikationen.

## Dateien
- `UVE_DESKTOP_VIDEO_EDITOR_IMPLEMENTATION_V4.md`: vollständige Entwicklungsanforderungen für Drag & Drop, Player, echte Timeline, UVE-Effekte und Offline-Rendering.
- `UVE_Desktop_Reference_UI.png`: vorherige Design-Visualisierung; als optische Referenz verwenden (nicht als technische Vorgabe).
- `UVE_DESKTOP_FULL_FEATURE_IMPLEMENTATION_V3.md`: vorherige Vollfunktionsanforderungen nur als Zusatzreferenz.

## So verwenden
ZIP entpacken und der Coding-KI gemeinsam mit dem aktuellen Original-Userscript und UVE GitHub Repository geben. Zuerst eine vollständige Quellcode-Funktionsinventur erstellen lassen; danach den lauffähigen Editor und den echten Videoexport.

**Explizit verboten:** Aufnahme des Players, Screen-Recording, Screenshots, MediaRecorder, Canvas Capture zur Exporterstellung.
